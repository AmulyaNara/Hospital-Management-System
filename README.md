# Hospital Patient Record and Visit Management System

# Project Overview

The Hospital Patient Record and Visit Management System is a web-based application designed to help hospitals and clinics manage patient records, doctor visits, diagnoses, prescriptions, and medical history efficiently. The system replaces traditional paper-based record management with a structured digital solution.

# End Users

## 1. Receptionist
The receptionist is responsible for patient registration and visit management.
# Features
* Register new patients
* Enter patient details:
                        * Name
                        * Age
                        * Gender
                        * Phone Number
                        * Address
                        * Blood Group
                        * Emergency Contact
* Generate a unique Patient ID
* Store patient records permanently
* Search patient records using Patient ID
* Create new visit entries for existing patients

## 2. Doctor
The doctor manages medical information and treatment records.
# Features
* View patient details
* View patient profile
* View previous visit history
* Add diagnosis information:
  * Problem/Disease
  * Symptoms
  * Notes
* Add prescriptions
* Update treatment records
* Maintain patient medical history

## 3. Admin
The admin controls and monitors the entire system.
# Features
# Doctor Management
* Add doctor accounts
* Remove doctor accounts
* Update doctor information
# Record Monitoring
* View all patient records
* View all visit records
* Monitor system reports
# Reports
* Daily patient reports
* Doctor-wise visit reports
* Patient history reports

## 4. Patient (Optional Module)
Patients can access their own medical records through a login portal.
# Features
* View visit history
* View prescriptions
* Download medical reports
